# 中国人能飞

一个参考经典小游戏《打企鹅》的纯前端街机游戏原型。飞行角色与击球手使用 PNG 精灵图，地雷、距离牌、粒子、三类空中道具与背景由 Canvas 2D 实时绘制；循环 BGM 与主要事件音效使用媒体素材，挥杆等辅助音效由 Web Audio 实时合成。

在线游玩：https://amam1yar3n.github.io/chinese-people-can-fly/

## 直接打开

可以直接双击项目根目录的 `index.html`。页面在 `file://` 环境下会自动加载已打包的 `offline/game.js`，不需要先启动服务器。

修改 TypeScript 源码后，重新生成离线文件：

```powershell
npm.cmd run build:offline
```

## 本地开发

需要 Node.js 20.19+ 或 22.12+：

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
npm.cmd run preview
```

完整构建会同时更新 `offline/game.js`，并在 `dist/` 中生成可部署产物。

## 操作方式

- 设置中可切换“神鹰黑手哥”、弹弓、人间大炮与东风快递发射车。神鹰黑手哥始终可用；点赞当前推荐视频可解锁弹弓，投币可解锁人间大炮，收藏可解锁东风快递发射车。互动资格通过 Toy JS SDK 实时核验，取消点赞或收藏后对应装置会重新锁定；未登录、SDK 不可用或网络异常时三个互动装置保持锁定。
- 历史最远距离和上次选择的装置偏好会保存在本地，并在已登录的 B站 Toy 环境中通过云存储跨设备同步。最远距离只用于成绩和历史统计，不再参与装置解锁；互动资格不会写入本地或云端。
- 神鹰黑手哥：鼠标点击、触摸屏幕或按空格键执行当前阶段动作。
- 首次操作：让左上方的角色开始倒栽下落。
- 第二次操作：让击球手播放一次完整挥杆。角色中心位于 `-40m` 至 `-5m` 高度时会立即击飞；角度随下落高度从 `75°` 线性降至 `15°`，窗口外操作则挥空。
- 弹弓：从弹兜中的黑衣飞行者附近按下并向左后方拖拽；松手发射。有效拉距为 `36–150` 个 Canvas 逻辑像素，对应 `70–180m/s`，发射角度映射范围为 `-80°–80°`；拖拽超出角度范围时弹兜维持在对应的最大角度，不会直接归位。短拉距或取消手势只会让弹兜归位；待机阶段空格无效。
- 人间大炮：第一次点击、触摸或按空格点燃引线，力度条的滑标从红色弱端开始，以 `0.4s` 单程速度持续往返；第二次输入锁定当前力度，并以固定 `26°`、`50–220m/s` 发射。
- 东风快递发射车：发射架直接装载原尺寸飞行姿态的黑衣飞行者；点击、触摸或按空格后立即以固定 `22°`、`260m/s` 发射。
- 接近地面下降时：在有效窗口内操作可触发打水漂。
- 孔明灯、六代机或 UFO 生效期间：输入会被忽略，效果自动完成。
- 停稳结算后第一次操作：只重置到当前击球手的待机状态；下一次操作才开始新一局。

移动端竖屏时游戏会暂停并提示旋转；恢复横屏后继续当前状态。页面切到后台时也会暂停模拟。

## 计分

总分实时按以下公式计算：

```text
floor(本局最远距离 / 10) + 成功水漂次数 × 5 + 红包数 × 50
```

孔明灯、六代机、UFO 和地雷助推产生的水平位移都会计入最远距离。HUD 左侧显示距离，右侧显示分数；结算显示总分、“你飞了 xx 米”与按距离分档的评语文案。

## 排行榜

右上角分数与设置按钮之间的领奖台按钮会打开最高单局分排行榜。排行榜使用 B站 Toy 榜位 1 的永久总榜，展示前 50 名玩家，并在底部固定显示“我”的名次与分数；打开排行榜时游戏和音乐会暂停，关闭后继续。

每局结算时会通过 Toy JS SDK 静默提交本局总分，服务端只保留玩家的历史最高单局成绩。榜单每次打开都会刷新；未登录时公共榜单仍可查看，个人区域会提示登录。SDK、登录态或网络不可用时会显示平台不可用说明，不影响普通网页、离线游戏、进度存档或后续游玩。

## 空中道具

- 每局前 150m 不生成道具；首个道具位于 150–250m，之后每隔 100–190m 随机生成一个。
- 类型权重为红包 50%、孔明灯 18%、六代机 18%、UFO 14%；六代机出现在 40–120m，UFO 只出现在 65–120m 高空。
- 拾取采用宽松的 20m 扫掠判定，避免高速移动时穿过道具。
- 红包：立即获得 50 分。
- 孔明灯：角色悬挂在灯下，保持水平速度，以 30m/s 上升 3 秒、共 90m，然后从零垂直速度开始下落。
- 六代机：角色变为飞翼，以拾取时水平速度与 150m/s 中的较大值定高飞行 3.5 秒；结束后的水平速度取拾取前水平速度与向前 120m/s 中的较大值，并从零垂直速度开始下落。飞行期间不再自动吸取红包，但直接碰到的红包仍可拾取。
- UFO：角色变为正面悬浮飞碟，以拾取时水平速度与 120m/s 中的较大值在拾取高度定高飞行 5 秒；结束后的水平速度取拾取前水平速度与向前 120m/s 中的较大值，并从零垂直速度开始下落。期间所有进入画面的红包都会自动追踪吸入。
- 孔明灯生效期间，拾取另一盏孔明灯会把剩余效果刷新为完整 90m/3 秒；拾取六代机或 UFO 会立即中断孔明灯并切换变身。六代机或 UFO 生效期间只处理红包，其他变身道具不会触发或刷新。

## 原有规则

- 击球初速度为 `150m/s`，出射角由挥杆命中时机映射到向右上 `15°–75°`。
- 成功水漂保留 80% 水平速度，并将 80% 入地垂直速度转为向上速度；低于初始速度 30% 时不能继续水漂。
- 首颗地雷仍在 420–650m 生成，后续地雷随机间隔为 250–900m。爆炸后水平速度变为 `max(|当前水平速度| × 1.1, 120m/s)` 并保持向前，垂直速度设为向上 90m/s。
- 地面每 200m 显示距离牌；未成功水漂时角色贴地滑行，并受地面摩擦减速至停止。

## 代码结构

```text
src/
├── main.ts          页面初始化、输入、固定时间步、HUD 与暂停控制
├── style.css        16:9 布局、HUD、结算层与竖屏遮罩
├── game/
│  ├── config.ts     游戏、物理、道具、镜头与配色参数
│  ├── types.ts      游戏内部状态类型
│  ├── launchers.ts  发射装置注册表、互动条件与解锁判断
│  ├── progress.ts   历史最远距离与装置偏好存档
│  ├── cloud-progress.ts Toy 云端进度读取、合并与写入队列
│  ├── leaderboard.ts Toy 排行榜配置、读取与最高分提交队列
│  ├── sprites.ts    角色 atlas、姿态锚点、挥杆帧与素材加载
│  ├── game.ts       状态机、物理、生成、碰撞、计分与 Canvas 绘制
│  └── audio.ts      媒体素材加载与 Web Audio 程序音效
└── platform/
   └── toy-sdk.ts    Toy JS SDK 安全加载、视频互动、云存储与排行榜适配
```

音频素材位于 `assets/audio/`：`launch-hit.mp3` 与 `batter-hit.mp3` 叠加用于神鹰黑手哥击球，`slingshot-release.mp3` 用于弹弓释放，`cannon-launch.mp3` 用于人间大炮发射，`missile-launch.mp3` 用于导弹发射车发射；`red-packet-pickup.mp3` 用于拾取红包，`sky-lantern-pickup.mp3`、`sixth-gen-jet-pickup.mp3` 与 `ufo-pickup.mp3` 分别用于拾取孔明灯、六代机与 UFO，`mine-trigger.mp3` 用于触发地雷，`water-skip.mp3` 用于成功打水漂。`bgm.m4a` 会在首次操作后开始循环，并在页面进入后台时暂停。
