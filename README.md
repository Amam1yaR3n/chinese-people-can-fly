# 中国人能飞

一个参考经典小游戏《打企鹅》的纯前端街机游戏原型。角色、击球手、球棍、地雷、距离牌、粒子、三类空中道具与背景都由 Canvas 2D 实时绘制；音效由 Web Audio 实时合成，不使用外部媒体素材。

在线游玩：https://amam1yar3n.github.io/chinese-people-can-fly/

## 直接打开

可以直接双击项目根目录的 `index.html`。页面在 `file://` 环境下会自动加载已打包的 `offline/game.js`，不需要先启动服务器。

修改 TypeScript 源码后，重新生成离线文件：

```powershell
npm.cmd run build:offline
```

## 本地开发

需要 Node.js 20.19+ 或 22.12+：

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
npm.cmd run preview
```

完整构建会同时更新 `offline/game.js`，并在 `dist/` 中生成可部署产物。

## 操作方式

- 鼠标点击、触摸屏幕或按空格键：执行当前阶段的唯一动作。
- 首次操作：让右上方的矩形角色开始下落。
- 第二次操作：让击球手挥杆；命中角度由挥杆时机决定。
- 接近地面下降时：在有效窗口内操作可触发打水漂。
- 孔明灯或六代机生效期间：输入会被忽略，效果自动完成。
- 停稳结算后再次操作：立即重置并开始新一局。

移动端竖屏时游戏会暂停并提示旋转；恢复横屏后继续当前状态。页面切到后台时也会暂停模拟。

## 计分

总分实时按以下公式计算：

```text
floor(本局最远距离 / 10) + 成功水漂次数 × 5 + 红包数 × 50
```

孔明灯、六代机和地雷助推产生的水平位移都会计入最远距离。HUD 左侧显示距离，右侧显示分数；结算显示总分与最远距离。

## 空中道具

- 每局前 150m 不生成道具；首个道具位于 150–250m，之后每隔 100–190m 随机生成一个。
- 类型权重为红包 50%、孔明灯 30%、六代机 20%；六代机只出现在 65m 以上的高空。
- 拾取采用宽松的 20m 扫掠判定，避免高速移动时穿过道具。
- 红包：立即获得 50 分。
- 孔明灯：角色悬挂在灯下，保持水平速度，以 30m/s 上升 3 秒、共 90m，然后从零垂直速度开始下落。
- 六代机：角色变为飞翼，以 150m/s 定高飞行 600m、共 4 秒；结束后水平速度固定为向前 120m/s，并从零垂直速度开始下落。期间所有进入画面的红包都会自动追踪吸入。
- 孔明灯生效期间，拾取另一盏孔明灯会把剩余效果刷新为完整 90m/3 秒；拾取六代机会立即中断孔明灯并切换为六代机。六代机生效期间仍只获取红包，其他变身道具不会触发。

## 原有规则

- 击球初速度为 `150m/s`，出射角由挥杆命中时机映射到向左上 `15°–75°`。
- 成功水漂保留 80% 水平速度，并将 80% 入地垂直速度转为向上速度；低于初始速度 30% 时不能继续水漂。
- 首颗地雷仍在 420–650m 生成，后续地雷随机间隔为 250–900m。爆炸后水平速度变为 `max(|当前水平速度| × 1.1, 120m/s)` 并保持向前，垂直速度设为向上 90m/s。
- 地面每 200m 显示距离牌；未成功水漂时角色贴地滑行，并受地面摩擦减速至停止。
