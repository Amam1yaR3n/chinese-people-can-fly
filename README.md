# 中国人能飞

一个参考经典小游戏《打企鹅》的纯前端街机游戏原型。项目不使用图片、字体、音频等外部媒体素材；角色、击球手、球棍、地雷、距离牌、粒子和背景均由 Canvas 2D 实时绘制，音效由 Web Audio 实时合成。

## 直接打开

可以直接双击项目根目录的 `index.html`。页面会在 `file://` 环境下自动加载已经打包好的 `offline/game.js`，不需要先启动服务器。

修改 TypeScript 源码后，需要重新生成离线文件：

```powershell
npm.cmd run build:offline
```

ChatGPT/Codex 内置浏览器出于安全限制不能导航到 `file://` 地址。如需在内置浏览器中查看，请按照下一节启动本地服务，再打开终端显示的 `http://localhost:端口/` 地址。

## 运行项目

需要 Node.js 20.19+ 或 22.12+。在项目目录执行：

```powershell
npm.cmd install
npm.cmd run dev
```

终端会显示本地访问地址。在 Windows PowerShell 执行策略禁止 `npm.ps1` 的环境中，请继续使用上面的 `npm.cmd`。

生产构建与本地预览：

```powershell
npm.cmd run build
npm.cmd run preview
```

完整构建会同时更新根目录的 `offline/game.js`，并在 `dist/` 中生成可部署产物。

## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 分支后，GitHub Actions 会使用 Node.js 24 安装依赖、构建 `dist/`，并将其部署到 GitHub Pages。首次发布需要在仓库设置中将 Pages 的构建来源设为 **GitHub Actions**。

## 操作方式

- 鼠标点击、触摸屏幕或按空格键：执行当前阶段的唯一动作。
- 首次操作：让右上方的矩形角色开始下落。
- 第二次操作：让击球手从预后摆姿势开始挥杆。过早或过晚都会挥空；命中角度随碰撞时机连续变化。
- 飞行下降并接近地面时：在落地前后约 220ms 的有效窗口内操作可触发水漂。每次近地下降只接受第一次操作，过早点按会消耗本次机会。
- 停稳结算后再次操作：立即重置并开始新一局。
- 右上角“声音”按钮：切换程序音效，不会触发游戏动作。

手机竖屏时游戏会暂停并提示旋转；恢复横屏后继续当前状态。页面切到后台时也会暂停模拟。

## 玩法规则

- 击球初速度固定为 `150m/s`，出射角根据挥杆时机映射到向左上 `15°–75°`。
- 成功水漂保留 75% 水平速度，并将 75% 入地垂直速度转为向上速度；低于初始速度 30% 时不能继续水漂。
- 每局随机生成稀疏地雷，首颗位于 420–650 米，后续间距为 200–1200 米。撞雷会将现有水平速度提高 12%、保证至少 `125m/s` 的向左助推，并给予 `72m/s` 的向上速度。
- 地面每 200 米显示距离牌；HUD 与结算成绩采用本局到达的历史最远整数米数。
- 未成功水漂时不产生被动反弹，角色只会贴地滑行，并以 `30m/s²` 的地面摩擦减速度更快停下。
- 击飞后镜头平滑跟随，并将角色稳定在画面宽度约三分之二处，为向左飞行方向保留更多前方视野。

## 代码结构

```text
src/
├─ main.ts          页面初始化、输入、固定时间步、HUD 与暂停控制
├─ style.css        16:9 布局、DOM HUD、结算层与竖屏遮罩
└─ game/
   ├─ config.ts     所有游戏、物理、镜头与配色参数
   ├─ types.ts      游戏内部状态类型
   ├─ game.ts       状态机、物理、碰撞、生成逻辑和 Canvas 绘制
   └─ audio.ts      Web Audio 程序音效
```

若要调整手感，优先修改 `src/game/config.ts` 中的 `GameConfig`；逻辑代码不包含重复的核心平衡参数。
